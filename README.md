## 部署到 GitHub Pages

1. 提交代码到 GitHub 仓库：
   ```bash
   git add .
   git commit -m "AI工具导航站 v1.0"
   git push
   ```

2. 在 GitHub 仓库 Settings → Pages → Source 选择 `main` 分支

3. 等待几分钟后即可访问：`https://ansengao105.github.io/ai-tools-nav`
